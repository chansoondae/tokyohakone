## 일정 수정 방법

일정 데이터는 모두 `lib/itinerary.ts` 한 파일에 있습니다. 홈의 "일정 한눈에 보기"와 일자별 페이지가 이 파일을 함께 사용합니다.

- `days` — 일차별 일정. `weekday`는 한 글자(`"목"`)로 적고, 화면에는 "목요일"로 표시됩니다.
- `flights` — 도슨트팀별 항공편
- `docents` — 도슨트 팀 이름 · 프로필 이미지 · 프로필 대체 텍스트

각 스팟은 `kind`에 따라 다르게 표시됩니다.

| kind | 표시 |
|---|---|
| `airport` | 공항 카드 |
| `museum` | 미술관 카드 (`exhibition`에 특별전 이름) |
| `free` | 자유시간 카드 (`options`에 추천 장소 목록) |
| `meal` | 식사 한 줄 |
| `move` | 이동 상자 (`description`에 부가 설명) |

한 팀만 가는 일정은 스팟에 `docent: "lee"` 또는 `docent: "chae"`를 적으면, 카드에 "○○○ 도슨트팀 일정" 표시와 도슨트 프로필이 함께 나옵니다.

그 밖의 수정 위치:

| 내용 | 파일 |
|---|---|
| 헤더 (로고 · 사이트 이름) | `components/layout/TopBar.tsx` |
| 홈 상단 배너 · 미술관 목록 | `components/home/HeroBanner.tsx` |
| 투어 요약 · 항공편 · 도슨트 프로필 | `components/home/TourSummaryCard.tsx` |
| 포함 · 불포함 | `components/home/InclusionAccordion.tsx` |
| 도슨트 연락처 (홈) | `components/home/ContactCTA.tsx` |
| 여행 정보 · 연락처 · 비상연락처 | `app/info/page.tsx` |
| 비짓재팬웹 안내 | `components/info/VisitJapanWeb.tsx` |
| 사이트 이름 · 공유 미리보기 | `lib/seo.ts`, `app/layout.tsx` |

## 이미지 추가 방법

1. `public/images/` 폴더에 이미지를 넣습니다. 파일명은 **영문 소문자 · 하이픈**으로 지어 주세요. (예: `kusama-museum.jpg`) 한글이나 공백이 들어간 파일명은 URL에서 문제가 생길 수 있습니다.
2. `lib/itinerary.ts`에서 해당 스팟의 `imagePath`에 경로를 적습니다. (예: `imagePath: "/images/kusama-museum.jpg"`) 숙소 사진은 일차의 `hotelImagePath`에 적습니다.
3. 큰 사진(수 MB)은 가로 1600px 정도로 줄여서 넣는 것이 좋습니다. (macOS: `sips -Z 1600 원본.jpg --out 새파일.jpg`)

이미지 파일이 없으면 사진 영역 없이 카드만 표시됩니다.
